# Images

- `design/` — the six social media graphics in the "Design Portfolio"
  section. See [design/README.md](design/README.md).
- `stats/` — the four verified dashboard screenshots shown in the "Work
  Highlights & Stats" cards. See [stats/README.md](stats/README.md).
- `logos/` — official tool logos used in the "Tools & Software" section. See
  [logos/README.md](logos/README.md).

There is no portrait folder: this site deliberately has **no profile photo**, so
the About Me section is text only and there is no image to upload there.

The stats screenshots show **aggregate platform metrics only** — no candidate
names, contact details or client correspondence appear in them. The design
graphics use placeholder branding (`LOGO`, `Logoipsum`, `company.com`).
