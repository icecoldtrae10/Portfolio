# Images

- `projects/` — optional visuals that fill the empty media slots in the "Work
  Highlights & Stats" section. See [projects/README.md](projects/README.md).
- `logos/` — official tool logos used in the "Tools & Software" section. See
  [logos/README.md](logos/README.md).

There is no portrait folder: this site deliberately has **no profile photo**, so
the About Me section is text only and there is no image to upload there.

There is no analytics folder either — the site does not display platform
screenshots or dashboards.
